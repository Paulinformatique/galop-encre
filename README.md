# Galop d'encre

Un film d'animation au trait noir de **Paul Guibert** : 40 secondes de course de chevaux à travers l'Ouest, en stop motion.

Ouvrir `index.html` dans un navigateur. Aucune dépendance, tout est dessiné en Canvas.

## Les plans

Sabots, ligne de départ, désert, canyon, rivière, saut du rocher, duel, orage, campement de nuit, arrivée, carton de fin.

## Cadence

Trois modes, à choisir sous l'animation :

- **Lisse** : 24 poses par seconde
- **En 2** : 12 poses par seconde, chaque pose tenue 2 images
- **En 3** : 8 poses par seconde, chaque pose tenue 3 images
